# Community Science Museum

Community Science Museum is a responsive, multi-page website created to promote an interactive science museum for children and families. The project focuses on engaging presentation, clear information architecture, accessibility, and performance using semantic HTML and CSS.

## Features

- Multi-page website with clear and intuitive navigation
- Responsive design for mobile, tablet, and desktop devices
- Accessible structure following WCAG guidelines
- Optimized images for fast loading
- SEO-friendly meta tags and semantic HTML
- Design tailored to a young target audience (ages 7–15)

## Prerequisites

No prerequisites required.  
The project runs in the browser using plain HTML and CSS.

## Getting Started

### Installation

```bash
npm install
```

### Running the project

```bash
npm run dev
```
